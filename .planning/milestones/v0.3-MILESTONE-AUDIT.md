## Cross-Phase Integration

- **`src/constants.rs`** is the single source of truth for all centralized literals. It is referenced by `src/client.rs`, `src/session.rs`, `src/proto/`, `src/upload.rs`, `src/har.rs`, `src/transient_400.rs`, `src/metrics.rs`, `src/attestation.rs`, `src/tool.rs`, `src/models.rs`, `src/chat.rs`, tests, and examples.
- Public API surface is unchanged except for a minimal set of constants made `pub` so that examples/tests can reuse them (`GEMINI_BASE_URL`, `APP_PATH`, `BATCHEXECUTE_PATH`, `HL`, `REQID`, `RT`, `RT_VALUE`, `FORM_URLENCODED`, `PNG`, `COOKIE`, `UPLOAD_BROWSER_LIKE`).
- Existing re-exports (`ANTI_XSSI_PREFIX`, `RPC_FRAME_MARKER`) through `src/proto/mod.rs` and `src/proto/indices.rs` are preserved.
- No public method signatures, struct fields, or enum variants were removed or changed.

## Gaps / Tech Debt

None blocking. Intentional residual inline literals remain in the following categories, all documented in phase summaries:

1. **Test fixtures** — captured batchexecute response payloads and WIZ/session HTML snippets are kept as raw literals so tests continue to assert against real captured protocol shapes.
2. **Parser error messages / diagnostics** — WIZ key names such as `S06Grb`, `oPEP7c`, and `FdrFJe` still appear in diagnostics and doc comments because they name real frontend keys.
3. **Doc comments** — `/app`, `wrb.fr`, etc. appear in documentation where they describe the protocol being wrapped.

The regression gate (`DENY_LIST`) is deliberately conservative and targets only high-risk protocol values that are cheap to centralize. It does not claim to eliminate every literal occurrence.
