<task type="auto">
  <name>Task 3: Add regression gate for eliminated magic strings</name>
  <files>clippy.toml, src/constants.rs, Cargo.toml</files>
  <action>
    Add a regression gate that fails CI if certain eliminated magic strings reappear as inline literals in `src/`.

    Option A (preferred): Use a compile-time regression test in `src/constants.rs` under `#[cfg(test)]`:
    - Add a test module `regression_tests` that uses `include_str!` macros to load every `.rs` file under `src/` and asserts that a deny-list of literals is not present outside of the `constants.rs` file itself.
    - The deny-list should include high-risk literals that should never be inlined again: `"/_/BardChatUi/data/batchexecute"`, `"rpcids"`, `"source-path"`, `"f.sid"`, `"S06Grb"`, `"oPEP7c"`, `"FdrFJe"`, `"wrb.fr"`, `"user"`, `"model"` (in non-test production code), `"image/png"`, `"x-goog-upload-command"`, `"bard-storage"`, `"application/json+protobuf"`, `"<redacted>"` only where it should come from the constant, etc.
    - Exclude test-only modules by checking the file path or by keeping the deny-list scoped to non-`#[cfg(test)]` code (the `include_str!` approach reads source text, so keep the list focused on obvious protocol literals).

    Option B (fallback): Add `disallowed-methods` or a custom clippy lint via `clippy.toml` is not expressive enough for literal strings. If the compile-time test is too fragile, document the fallback in the plan and use a small Python/shell script invoked by `cargo xtask regression-gate` instead.

    Implement Option A. The test must:
    - Walk `src/` using `std::fs::read_dir` at test time.
    - Skip `src/constants.rs`.
    - Read each file and reject any occurrence of the deny-list literals.
    - Print a helpful message naming the file and literal.

    Do NOT add the deny-list literals as comments or doc strings in `src/constants.rs` in a way that would trip the gate; the gate skips `src/constants.rs`.
  </action>
  <verify>
    <automated>cargo test --lib constants::regression_tests -- --nocapture</automated>
  </verify>
  <done>
    - Regression test passes on the refactored codebase.
    - Inserting a deny-list literal into a non-constants source file causes the test to fail.
  </done>
</task>
