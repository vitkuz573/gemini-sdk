# Milestone v0.3: Magic String Elimination

**Status:** ✅ SHIPPED 2026-08-11
**Phases:** 13-16
**Total Plans:** 4

## Overview

Centralize all literal protocol, transport, model, MIME, header, HAR, tracing, attestation, and tool-schema strings as named constants, clean up tests/examples, and add a regression gate so the codebase stays maintainable as the protocol surface grows.

## Milestone Summary

**Key Decisions:**

- Centralize cross-cutting strings in a single `src/constants.rs` module rather than scattering constants per feature module.
- Keep constants `pub(crate)` unless already public or needed by examples/tests; public API surface is preserved.
- Preserve existing re-exports (`ANTI_XSSI_PREFIX`, `RPC_FRAME_MARKER`) through `src/proto/mod.rs` and `src/proto/indices.rs` to avoid breaking downstream consumers.
- Allow a minimal public subset of constants (`GEMINI_BASE_URL`, `APP_PATH`, `BATCHEXECUTE_PATH`, etc.) so examples and integration tests can reuse them without duplicating literals.
- Use a runtime regression test that walks `src/` at test time rather than clippy lints, because the deny-list is focused on high-risk protocol literals.
- Intentionally keep raw captured protocol shapes in test fixtures and parser diagnostics as inline literals; the regression gate skips `src/constants.rs` and targets only reintroduction of already-centralized high-risk values.

**Issues Resolved:**

- Eliminated inline protocol literals across `src/client.rs`, `src/session.rs`, `src/proto/`, `src/upload.rs`, `src/har.rs`, `src/transient_400.rs`, `src/metrics.rs`, `src/attestation.rs`, `src/tool.rs`, `src/models.rs`, `src/chat.rs`, tests, and examples.
- Completed the RPC-ID constant set including `otAQ7b` (`OTAQ7B_RPC_ID`) and `Fd0Qje` (`GET_USER_STATUS_RPC_ID`).
- Centralized WIZ/session extraction keys (`S06Grb`, `oPEP7c`, `FdrFJe`, `cfb2h`, `f.sid`) so protocol drift updates have a single source of truth.
- Removed duplicated user-agent, sec-ch-ua, and static header literals from request construction.
- Replaced duplicated MIME type and model/category strings in chat, upload, and model derivation code.

**Issues Deferred:**

- Full OAuth / refresh-token flow remains future work (AUTH-V2-01).
- Resumable upload with explicit chunk size control remains future work (MEDIA-V2-01).
- Schema-aware WIZ payload validation and automatic protocol drift detection from live HAR captures remain future work (PROTO-V2-01, PROTO-V2-02).
- Batch/async tool execution and conversation branching remain future work (ADV-V2-01, ADV-V2-02).

**Technical Debt Incurred:**

- A small public subset of constants was promoted to keep examples/tests DRY; this slightly expands the public API surface. If desired, it can be narrowed in a future release.
- `const_format` was added as a dependency solely for test-time URL assembly in `src/har.rs`; it is not used in production code.
- The regression gate deny-list is deliberately conservative and does not claim to eliminate every literal occurrence in `src/`.
