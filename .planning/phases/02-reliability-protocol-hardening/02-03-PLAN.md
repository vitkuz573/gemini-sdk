<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| upstream byte stream -> generate_stream adapter | Untrusted chunked bytes are buffered and parsed incrementally. |
| caller prompt -> slot 0 | System instruction is concatenated with user prompt; must not break WIZ array shape. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-07 | Denial of Service | `generate_stream` byte buffer | medium | mitigate | Cap buffer growth or stream line-by-line; never hold the entire unbounded body in memory. |
| T-02-08 | Tampering | system instruction injection | low | mitigate | Treat instruction as opaque text; prepend verbatim without interpreting as WIZ structure. |
| T-02-09 | Information Disclosure | stream error messages | low | mitigate | Use `Error::Parse`/`Error::Request` constructors that do not include cookies or tokens. |
| T-02-SC | Tampering | cargo installs | low | accept | `bytes` may already be a transitive dependency of reqwest; if added explicitly, verify via cargo. |
</threat_model>
