    1. Add to `UsageStats`:
       ```rust
       pub fn requests_today(&self) -> Option<u64> {
           Self::extract_first_u64(&self.value, USAGE_TOTAL_INDEX, USAGE_TODAY_INDEX)
       }
       pub fn requests_total(&self) -> Option<u64> {
           Self::extract_first_u64(&self.value, USAGE_TOTAL_INDEX, USAGE_TOTAL_INDEX)
       }
       ```
       Where `USAGE_TOTAL_INDEX = 1` and `USAGE_TODAY_INDEX = 2` refer to positions inside the second element of the top-level array (index 1 of top-level), with the second-to-last bucket representing total and last bucket representing today.
    2. Implement a private helper that walks the array shape safely:
       - `value` must be an array.
       - `value.get(1)` must be an array of at least `bucket_index + 1` buckets.
       - `bucket[bucket_index]` must be an array with a first element that parses as `u64`.
    3. If the shape does not match, return `None`.
    4. Keep `value()` unchanged.
