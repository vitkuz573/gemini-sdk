<feature>
  <name>Session snapshot save/restore</name>
  <files>src/auth.rs, src/session.rs, src/chat.rs, src/client.rs, src/lib.rs, src/client/snapshot_tests.rs or tests/snapshot_tests.rs</files>
  <behavior>
    - `Conversation::save` returns a JSON string containing messages, model category, and a format version.
    - `Conversation::restore` parses the same string and returns an equivalent `Conversation`.
    - `GeminiClient::save_session` returns a JSON string containing credentials (with secrets), session state, and optionally the current conversation.
    - `GeminiClient::restore_session` parses the string and returns `(GeminiClient, Option<Conversation>)` equivalent to the saved pair.
    - Snapshot format includes `format_version: 1` for forward compatibility.
    - Snapshot Debug does not print credential values.
  </behavior>
  <implementation>
    1. Add `Serialize`/`Deserialize` to `Credentials` without changing its redacted `Debug` impl.
    2. Add `Serialize`/`Deserialize` to `ChatMessage`, `ContentPart`, `ImageSource` (and the new audio/video sources), `Conversation`, `GenerationConfig`, `ThinkingLevel`, and `ModelCategory`.
    3. Add a private `Snapshot` struct in `src/session.rs` with `format_version: u32`, `credentials: Credentials`, `session: SessionState`, and `conversation: Option<Conversation>`.
    4. Implement `Conversation::save`/`restore` via serde_json.
    5. Implement `GeminiClient::save_session`/`restore_session` using the snapshot, locking the internal cookies/session mutexes.
    6. Re-export `Snapshot` from `src/lib.rs`.
  </implementation>
</feature>
