| SDK -> model | Tool arguments parsed from model output are untrusted. |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-05-01 | Spoofing | Tool invocation | high | mitigate | Only invoke tools registered by caller; reject unknown tool names. |
| T-05-02 | Information Disclosure | ToolError messages | medium | mitigate | ToolError must not include raw args or secrets; keep messages generic. |
| T-05-03 | Tampering | Tool arguments | medium | mitigate | Validate args shape in Tool::invoke; use JSON schema as guidance. |
</threat_model>
