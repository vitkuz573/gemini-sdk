<feature>
  <name>Injectable reqwest::Client constructor</name>
  <files>src/client.rs, tests/unit/http_client.rs</files>
  <behavior>
    - `GeminiClient::from_http_client(client: reqwest::Client, credentials: impl Into<Cookies>) -> Result<Self>` builds a client using the provided `reqwest::Client`.
    - No `Client::builder()` call is made; the injected client is stored as-is.
    - Existing constructors (`from_cookie_header`, `from_credentials`) continue to build a default client.
  </behavior>
  <implementation>
    Add a new private constructor `with_http_client(cookies: Cookies, config: ClientConfig, http: Client) -> Result<Self>` that creates `Inner` with the supplied client. Implement `from_http_client` by validating cookies and delegating to `with_http_client`. Keep `with_config` unchanged for existing callers.
  </implementation>
</feature>
