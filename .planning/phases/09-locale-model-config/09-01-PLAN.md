<objective>
Implement four thin public APIs on `GeminiClient` for the undocumented locale/model configuration batchexecute RPCs (`cYRIkd`, `whPPme`, `Te6DCf`, `ku4Jyf`). All responses are wrapped in `serde_json::Value` containers to avoid brittle structs. The work follows the existing `src/user_profile.rs` module pattern and uses configurable `base_url` + Wiremock fixtures for tests.

Purpose: Complete the locale/model configuration surface of the v0.2 API expansion milestone while preserving forward compatibility against protocol drift.
Output: New `src/locale_model_config.rs` module, four client methods, re-exports, four fixtures, and integration tests.
</objective>

  <files>src/locale_model_config.rs</files>
  <action>
    Create `src/locale_model_config.rs` mirroring `src/user_profile.rs` patterns.

    Define `pub(crate) const` RPC IDs: `CYRIKD_RPC_ID = "cYRIkd"`, `WHPPME_RPC_ID = "whPPme"`, `TE6DCF_RPC_ID = "Te6DCf"`, `KU4JYF_RPC_ID = "ku4Jyf"`.

    Define four public wrapper structs, each with a single private `value: serde_json::Value` field and a `pub fn value(&self) -> &serde_json::Value` accessor:
    - `LocaleTools`
    - `ModelConfig`
    - `LocaleConfig`
    - `ToolsConfig`

    Each struct derives `Debug, Clone, PartialEq` and has a `#[must_use]` accessor with a doc comment.

    Implement payload builders returning `serde_json::Value`:
    - `pub fn build_get_locale_tools_payload(language: &str) -> Value` → `[language]`
    - `pub fn build_get_model_config_payload(language: &str) -> Value` → `[language, null, [4]]`
    - `pub fn build_get_locale_config_payload(language: &str) -> Value` → `[[language], [1, 2]]`
    - `pub fn build_get_tools_config_payload(language: &str) -> Value` → `[language, null, null, null, 4, null, null, [1, 3, 7, 17], null, []]`

    Implement response parsers:
    - `pub fn parse_locale_tools_response(body: &str) -> Result<LocaleTools>`
    - `pub fn parse_model_config_response(body: &str) -> Result<ModelConfig>`
    - `pub fn parse_locale_config_response(body: &str) -> Result<LocaleConfig>`
    - `pub fn parse_tools_config_response(body: &str) -> Result<ToolsConfig>`

    Each parser must:
    1. Strip the XSSI prefix using `crate::proto::strip_xssi_prefix`.
    2. Parse the outer batchexecute envelope and locate the RPC entry matching its RPC ID (reuse the `find_rpc_entry` / `extract_payload_str` logic from `user_profile.rs`, copying the helpers if necessary).
    3. Parse the inner payload string into `serde_json::Value`.
    4. Return the wrapper struct containing that value.

    Include `#[cfg(test)] mod tests` with:
    - One payload-shape test per builder asserting equality against `serde_json::json!(...)`.
    - One parser test per parser using a synthetic batchexecute body with XSSI prefix and asserting the extracted `Value` matches the expected payload.
    - One test for the wrapped-array envelope shape per parser (copy the wrapped-array pattern from `user_profile.rs` tests).

    Do NOT create brittle typed structs for the inner payloads. Do NOT add new dependencies.
  </action>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Client → Gemini frontend | Untrusted network; cookies and RPC payloads cross this boundary. |
| SDK public API → internal parser | Callers receive opaque `serde_json::Value` wrappers; no PII is strongly typed. |
| Test → mock server | Integration tests use synthetic fixtures; no live secrets. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-09-01 | Information Disclosure | `get_locale_tools` / `get_model_config` etc. | low | accept | Responses are opaque JSON values; no PII is parsed or logged at info level. Existing cookie redaction in `Cookies::Debug` covers auth headers. |
| T-09-02 | Tampering | Request payloads in transit | medium | mitigate | Reuse existing HTTPS transport and retry logic; no plaintext fallback. Configurable `base_url` still defaults to `https://gemini.google.com`. |
| T-09-03 | Denial of Service | Parser on malformed batchexecute envelope | low | mitigate | Parser returns structured `Error::Parse` instead of panicking; unit tests cover missing RPC entries and wrapped arrays. |
| T-09-04 | Elevation of Privilege | Test helper `inner_session_for_tests()` | low | accept | Already public and documented as test-only; no new capabilities added by this phase. |
| T-09-SC | Tampering | No new packages installed | — | mitigate | No package-manager install tasks; existing `wiremock` dependency is reused. |
</threat_model>
